Fundamentos del Sistema de E/S

⌨️
Periféricos de Entrada
Los periféricos de entrada son dispositivos de hardware que permiten al usuario o al entorno introducir datos e instrucciones al sistema computacional. Convierten información del mundo físico (presión, movimiento, sonido, luz) en señales eléctricas digitales interpretables por la CPU.
Ejemplos comunes
⌨️ Teclado 🖱️ Ratón 🎙️ Micrófono 📷 Cámara Web 🖨️ Escáner 🕹️ Gamepad
🔌
Controlador de E/S
El controlador de E/S (I/O Controller) es un circuito integrado especializado que actúa como intermediario entre el periférico y el bus del sistema. Se encarga de:
  • Gestionar interrupciones (IRQ)
  • Administrar el Acceso Directo a Memoria (DMA)
  • Convertir protocolos de comunicación
  • Controlar el flujo de datos y timing
🔄
Bus del Sistema
El bus del sistema es el canal de comunicación compartido que conecta todos los componentes del computador. Está formado por tres buses lógicos:
  • Bus de Datos: transfiere los datos (8–64 bits)
  • Bus de Direcciones: indica la ubicación en memoria
  • Bus de Control: coordina lectura/escritura y sincronización
⚡
CPU — Unidad Central de Procesamiento
La CPU es el cerebro del sistema. Recibe las señales de interrupción del controlador de E/S, suspende temporalmente su tarea actual y ejecuta el manejador de interrupciones (ISR) del Sistema Operativo. Ciclo de operación:
  • Fetch → Decode → Execute → Writeback
  • Gestión de interrupciones hardware
  • Llamadas al sistema (syscalls)
💾
Memoria RAM
La RAM (Random Access Memory) es la memoria principal de trabajo del sistema. Almacena temporalmente los datos mientras son procesados por la CPU. Características clave:
  • Volátil: pierde datos al apagar el equipo
  • Rápida: acceso en nanosegundos
  • Los datos de E/S se almacenan en buffers en RAM
  • El S.O. gestiona el espacio mediante paginación
🖥️
Sistema Operativo
El S.O. es la capa de software que gestiona todos los recursos hardware. En el contexto de E/S, el kernel:
  • Recibe la interrupción y ejecuta el driver del dispositivo
  • Transfiere datos del buffer del controlador a la RAM
  • Decide si los datos deben persistirse en disco
  • Proporciona API de E/S (read(), write(), ioctl())
📡
Controlador de Disco
El controlador de disco gestiona la comunicación entre el S.O. y el disco físico. Maneja protocolos estándar:
Interfaces
SATA III NVMe / PCIe SAS ATA
Traduce comandos lógicos del S.O. (leer sector X) en comandos físicos para los actuadores del disco.
🗄️
Disco Duro / SSD
El almacenamiento permanente conserva los datos incluso sin energía. Dos tecnologías principales:
  • HDD: platos magnéticos, cabezal físico, ~100 MB/s
  • SSD: memoria flash NAND, sin partes móviles, ~550 MB/s
  • NVMe SSD: conexión PCIe directa, hasta 7 GB/s
El sistema de archivos (NTFS, ext4, APFS) organiza los datos en el disco.
